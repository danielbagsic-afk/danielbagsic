# Daniel Bagsic portfolio

A responsive, single-page portfolio site for Daniel U. Bagsic. The website is plain HTML, CSS, and JavaScript so it can be deployed directly with GitHub Pages, Netlify, or Vercel.

## Assets to add

- Add the supplied portrait at `assets/daniel-bagsic-portrait.jpg` to replace the styled fallback in the hero.
- The résumé viewer currently uses the Google Drive PDF supplied in the project brief. It includes a Drive download link and an open-in-new-tab option; Drive access settings must allow visitors to view it.
- No certificates are claimed or included. To publish verified certificates, add the actual PDF/image files and entries to the `certificates` array in `index.html`.

## Deploy with GitHub Pages

In repository settings, enable GitHub Pages for the `main` branch and `/ (root)`. The site's entry point is `index.html`.
